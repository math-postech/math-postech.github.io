Lecture 20: Singular Value Decomposition ​

Theme: A real matrix sends a round ball to an ellipsoid. Singular value decomposition records the input axes, the output axes, and the axis lengths.

1. The Guiding Question ​

Start with a real matrix

A:Rn⟶Rm.

The geometric question is:

What does A do to the unit ball?

The answer is:

round ball→ A ellipsoid with orthogonal axes.

Singular value decomposition is the algebraic description of this picture.

2. The Axis Equation ​

We want special input directions vi such that their outputs land exactly on the output axes:

Avi=σiui.

Here:

SymbolMeaning
viinput axis direction, living in the domain
σiaxis length, a nonnegative number
uioutput axis direction, living in the codomain

The singular values are ordered as

σ1≥σ2≥⋯≥0.

They are lengths, so they cannot be negative.

3. Why We Look at ATA ​

The matrix A may be rectangular, so we do not diagonalize A directly.

Instead, measure how much A stretches an input vector x:

∥Ax∥2=(Ax)T(Ax)=xTATAx.

So

G=ATA

is the stretch-measuring matrix on the input side.

It is real symmetric:

(ATA)T=ATA.

Therefore the real symmetric spectral theorem applies.

4. Find the Input Axes ​

Orthogonally diagonalize ATA:

ATA=VΣ2VT.

Equivalently, the columns vi of V satisfy

ATAvi=λivi.

Because

λi=viTATAvi=∥Avi∥2≥0,

we write

λi=σi2,σi=λi.

Thus

ATAvi=σi2vi.

The vectors vi are the input axes on the unit circle/ball.

5. Find the Output Axes ​

If σi>0, define

ui=Aviσi.

Then

Avi=σiui.

Also, ui has length 1 because

∥ui∥=∥Avi∥σi=1.

For i≠j,

uiTuj=(Avi)T(Avj)σiσj=viTATAvjσiσj=σj2σiσjviTvj=0.

So the output vectors ui are orthonormal.

6. Zero Singular Values ​

If σi=0, then

∥Avi∥2=viTATAvi=0.

Therefore

Avi=0.

So zero singular values correspond to invisible input directions, i.e. null-space directions.

If the nonzero output vectors u1,…,ur do not fill all of Rm, complete them by the projection-complement method from the previous projection lectures.

Collect the known orthonormal vectors into a matrix:

B=(|||u1u2⋯ur|||).

The orthogonal projection onto their span is

P=BBT.

The complement projection is

I−P.

Now diagonal cross-fill the orthogonal projection I−P:

I−P=wr+1wr+1T+⋯+wmwmT.

These vectors are the missing output axes:

ur+1=wr+1,…,um=wm.

This is exactly the method from Lecture 10: Constructing Projections: cross-fill the projection and its complement to obtain a complete orthonormal basis.

7. Stack the Axis Equations ​

For each input axis,

Avi=σiui.

Stack all columns:

A(|||v1v2⋯vn|||)⏟V=(|||u1u2⋯um|||)⏟UΣ⏟axis lengths.

Thus

AV=UΣ.

Since V is orthogonal, V−1=VT, and hence

A=UΣVT.

8. The SVD Theorem ​

For every real m×n matrix A, there exist orthogonal matrices U,V and a rectangular diagonal matrix Σ with nonnegative entries such that

A=UΣVT.

Geometrically:

PieceMeaning
Vorthonormal input axes
Σaxis lengths of the output ellipsoid
Uorthonormal output axes

9. Method Summary ​

To compute a singular value decomposition:

  1. Compute ATA.
  2. Orthogonally diagonalize it:ATA=VΣ2VT.
  3. Read singular values from square roots of eigenvalues:σi=λi.
  4. For each σi>0, computeui=Aviσi.
  5. Complete the ui's by projection complement:B=(u1 ⋯ ur),P=BBT,then diagonal cross-fill I−P to get the missing orthonormal vectors.
  6. ConcludeA=UΣVT.

10. Final Picture ​

SVD is the axis system of a linear transformation:

text
input vector
   ↓ measure in orthonormal input axes V
coordinates
   ↓ stretch by singular values Σ
ellipsoid coordinates
   ↓ rebuild in orthonormal output axes U
output vector

In one line:

input axes vi→Aaxis lengths σi along output axes ui.
